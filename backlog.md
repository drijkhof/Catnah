# Backlog

Future wishes, as tickets. Nothing here is built yet — this is the list we talk
about and pick from. What *is* built is described in [`work.md`](work.md), and
the decisions taken along the way are in [`questions.md`](questions.md).

**Statuses**: `todo` · `in progress` · `blocked` · `icebox`

When a ticket is built, what it changed is written up in `work.md` and **the
ticket is deleted from here**. So this file is only ever what is still wanted.
Numbers are not reused, which is why there will be gaps.

## 5. De bar op Pluto als huisje met een binnenkant — `todo`

Op Pluto staat een huisje met een deur. Door de deur kom je in een eigen
"bar"-level, waar alleen de bar is. Daar zoomt de camera in, net als bij Bob,
zodat je echt in de bar zit; weglopen brengt je weer naar buiten.

## 7. Raketbenzine voor een tijdje, met een meter — `todo`

Bij de bar op Pluto: raketbenzine maakt de raket veel sneller, maar maar voor
een tijdje. Naast de hartjes staat een meter die laat zien hoeveel benzine er
nog is.
